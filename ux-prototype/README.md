# ClimbCrew — prototype UX public

Prototype statique, responsive et autonome d’une nouvelle interface ClimbCrew.

- aucune API et aucune connexion à la base de production ;
- données fictives clairement identifiées ;
- navigation optimisée pour téléphone et ordinateur ;
- tableau de bord centré sur la prochaine action ;
- vue semaine avec les séances placées sous chaque jour ;
- recherche et filtrage des voies ;
- inscription et saisie de réalisation simulées ;
- progression CPR et mode sombre.

Le prototype est déployé automatiquement par GitHub Pages depuis la branche `agent/public-ux-prototype`.
